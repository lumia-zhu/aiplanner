📋 下一步操作（需要您手动完成）：
-----------------------------------

第 1 步：配置 Supabase
----------------------
1. 访问 https://supabase.com 注册/登录
2. 创建新项目或选择现有项目
3. 进入 Settings → API，复制：
   - Project URL
   - anon public key
4. 打开项目中的 .env.local 文件
5. 替换占位符为您的实际值：
   NEXT_PUBLIC_SUPABASE_URL=<您的 Project URL>
   NEXT_PUBLIC_SUPABASE_ANON_KEY=<您的 anon public key>

第 2 步：设置数据库
-------------------
1. 在 Supabase 控制台，打开 SQL Editor
2. 运行项目中的 database/schema.sql 文件内容
   （详细步骤请查看：快速数据库设置.md）

第 3 步：启动项目
-----------------
在命令行中运行：
   cd D:\CodeProject\AI_Task_manager\aiplanner
   npm run dev

然后在浏览器访问：http://localhost:3000
